GESTURE AI - MOBILE GITHUB UPLOAD GUIDE (HINDI)

IMPORTANT:
1) ZIP ko pehle File Manager me Extract karein.
2) Extract hone ke baad GestureAI_Starter naam ka folder dikhega.
3) GitHub repository ke ROOT me isi folder ke ANDAR ki files/folders upload karni hain.
4) GestureAI_Starter naam ka outer folder GitHub par as a folder upload mat karein. Uske andar ka content repository ke root me jayega.
5) File/folder ke naam bilkul same rakhein. Capital/small letters aur dot (.) miss na karein.

GITHUB MOBILE:
- Repository kholo.
- Add file > Upload files dabao.
- File picker me extracted GestureAI_Starter folder kholo.
- Agar picker folder select karne de, to andar ke items select karo; outer GestureAI_Starter folder ko upload mat karo.
- Agar nested folders select nahi hote, to GitHub me Add file > Create new file use karke file path likho (example: app/src/main/assets/index.html). Lekin har file ka poora content paste karna padega; isliye ZIP ko extract karke multi-select upload zyada aasaan hai.
- Upload ke baad Commit changes dabao.

BUILD:
- Repository me Actions kholo.
- "Build Gesture AI APK" workflow kholo.
- "Run workflow" dabao.
- Run complete hone par green tick aana chahiye.
- Run ke andar Artifacts me "Gesture-AI-debug-apk" download karo.
- ZIP artifact extract karke APK install karein.

LIMIT:
Ye starter demo/WebView interface hai. Ye abhi real hand/face tracking, arbitrary apps ko gesture se control karna, ya reliable background camera service implement nahi karta. Un features ke liye native Android services aur on-device recognition code alag se banana hoga.
